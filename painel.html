Relações de troca

Como calculamos: Boi × Bezerro usa um boi gordo padrão de 18,5@ — ou seja, quantos bezerros a venda de um boi gordo permite comprar. Boi × Milho mostra quantas sacas de milho uma única arroba de boi gordo compra (indicador clássico de custo de engorda/confinamento).
Sobre os dados: este painel busca automaticamente os arquivos historico_consolidado.csv (diário) e historico_mensal_consolidado.csv (médias mensais, ~24 meses) gerados pelo script coleta_cepea.py (rodando via GitHub Actions) — toda vez que a página é aberta, ele carrega a versão mais recente direto do repositório, sem precisar editar este HTML.
